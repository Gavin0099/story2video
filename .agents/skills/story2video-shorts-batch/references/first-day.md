# CluePause Shorts 首日觀察

1. 在正確頻道的 YouTube Studio 開「數據分析 → 進階模式 → 特殊報表 → 影片發布後 24 小時內的成效」。驗證時間範圍為前 24 小時，而且發布日期篩選涵蓋要比的片。依影片 ID 對照已公開版本；私人片從各自公開後算起。[YouTube 進階模式](https://support.google.com/youtube/answer/9717005?hl=zh-Hant)
2. 每片記錄發布時間、擷取時間、報表時窗、公開觀看、按讚、互動觀看、Shorts 動態曝光、選擇觀看比例、平均觀看比例。用選擇觀看比例看開頭留人，用平均觀看比例看收看時間相對片長。觀眾留存曲線可用時，比較同片揭曉前後，記揭曉秒數與曲線時窗。[Shorts 內容成效](https://support.google.com/youtube/answer/12220281?hl=zh-Hant)
3. 一個欄位的數字若來自「自發布至今」或即時卡片，附當時片齡和來源。首日報表缺值保持空白，保留資料不足或處理中的原文。YouTube 留存通常需要 1 至 2 天處理。[觀眾續看率](https://support.google.com/youtube/answer/9314415?hl=zh-Hant)
4. 觀看與讚來自同一觀察窗，才計算每千次觀看的讚數。對照不同類型的片數、中位數、曝光、流量來源和片長。指出值得續測的具體開場、升級或揭曉做法。只有個別影片突出或分母太小時，保留為觀察。依專案記錄第 7、28 天，與首日分開。

現有 CluePause 記錄可從 `artifacts/market-twelve/market-windows.csv` 與各 `publication-*.json` 延續。僅在對上相同批次影片 ID 時沿用其時間戳。
