# 鏡頭比較試驗（s09-methods-v1.1）

當批次有可測的呈現問題且要做對照時，從一支適合的原創作品先做一組單因素比較。基準和候選各保留 revision、成片雜湊和測試素材，同一版本記所選手法、改動區間、原始聲軌／字幕、實際時間碼及成片證據。可依 [S09 方法與公開影格複核](../../../../experiments/issue-32/s09-method-evidence.md) 選一項假設。公開實例的劇情、人物、媒體與音軌留在來源。

1. **選一個可回答的問題。** 寫下觀眾在開場、下一步及揭曉可各看到什麼。每個重要鏡頭記同一物件或現象的開始和結束狀態。劇情需有簡短的說明主線，動作時間軸還需容納辨認證據的空間。把場記的估計和輸出實測分開。
2. **做同稿兩版。** A 是基準，B 僅修改下表的一項因素。固定故事／事實、主要旁白、字幕、片長及音量。因素本身需要變更聲畫或時長時，就把變動列為實驗因素，重核受影響的 Gate 與其他差異。先用低成本短動態樣帶驗證工程可行，再依本次授權製作。修改答案、素材或用途時使用既有重新審查步驟。
3. **驗證畫面，再記看片觀察。** 先完整播放並做手機靜音檢查。以實際配音與 cue 核對時間碼，逐格確認狀態開始、接觸／動作與結果都存在。無聲可讀與英／繁中正式字幕分開驗證。Owner 可獨自比較兩版，保留其觀察和是否事先知道答案。若另有首看樣本，可讓新觀眾各看一版，固定播放大小、語言與提問，記原話、樣本數和是否事先知道內容。
4. **記結論及證據。** 對每個結果記明是原檔方法、公開可見片段、本地 QA、Owner 觀察、真人首看或市場量測。先約定怎麼判讀，例如靜音仍能比對兩次操作，且必要因果完整。觀眾樣本不足就寫 INSUFFICIENT。試驗以單片、單因素為起點，工程、編輯與市場各自留狀態，沿用原本 Gate 和 Owner 授權。

| 類型與因素 | A／B 原創示意 | 盲測問題與反例 |
| --- | --- | --- |
| 海龜湯／揭曉視角 | A 揭曉時切女主角反應。B 同秒數切回交件前已拍過的封條破角，旁白、解答與片長相同。先寫最強替代解，記破角支持哪個判斷，以及照片何時讓觀眾看到。 | 「你用哪個先前畫面排除另一個可能？」若封條破角在這一刻第一次出現，觀眾原先無從推理，先補公平線索。 |
| 日常詭異／兩次操作構圖 | A 第二次按印表機測試鍵改拍人物。B 同一視角拍兩次，一次印出單張測試列，另一次出現印著空房座位圖的紙。操作前寫預期，兩次都保留按鍵、退手、出紙。 | 「她做了什麼，哪裡開始與上一次不同？」同時改紙、時間與出紙口位置會混淆異常來源。 |
| 都市怪談／結尾後果可辨性 | A 電鈴響後以暗閃結束。B 同段在微亮區保留門口銅牌，從公寓號切成一個空白位置，畫面基線先交代響鈴時銅牌通常不變。兩版共用音軌。 | 「揭曉時哪項規律被打破，結果是什麼？」如果換成角色忽然尖叫，可能只知道發生了怪事。 |
| 科普／首段因果現象 | A 開頭展示叉匙與水槽的廣角。B 同時長改近景，同時見湯匙內、外側映像方向；後段回到固定原物驗證原因，近物焦距條件以已查證的稿件為準。 | 「你看到哪個差異，後段圖解說明了什麼？」若畫面把凹面在所有距離都畫成倒像，就先修正主張範圍。 |

只有公開觀眾資料經授權且符合既有量測窗時，才追加市場證據。公開預覽讀法、台詞、構圖或本人首看都可以生成假設，是否改善留存留待資料。
