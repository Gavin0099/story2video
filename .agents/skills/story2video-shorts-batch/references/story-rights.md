# Story Rights Gate

CluePause 以原創為主。研究經典時，交給 Writer 的簡報只帶抽象推理機制和短影音檢查項目。Writer 自行設計事件、人物關係、線索與解答因果。比對原稿與來源時，尤其要看有辨識度的情節組合。換名字、重寫旁白、翻成英文或加上出處都無法替代需要取得的改作授權。具體的事件順序、人物關係與發展可能受著作權保護。 [著作權法第 10 條之 1、第 26 條之 1 及第 28 條](https://law.moj.gov.tw/LawClass/LawAll.aspx?PCode=J0070017) · [智慧財產局電子郵件 1021016](https://www.tipo.gov.tw/tw/copyright/692-14534.html)

經典特別企劃只使用已查證可用的特定版本。原版本、當代譯本、插圖、旁白錄音等各自查核。網頁或書目可用來找到版本與出處。作者或首次發表不明時，保留待查紀錄。

## 依使用依據查核

| 使用依據 | 通過需要的證據 |
| --- | --- |
| 原創 | 記錄作者或製作來源、凍結稿和參考機制。記錄與相關來源在主要事件、事件順序、人物關係、關鍵線索與解答因果的比對。仍有具體情節相似疑義時，補查或改成獨立的新稿。 |
| 公共領域 | 記錄確切來源版本、作者、首刊資料、作品類型及判定日期。留存所用版本在發行範圍內各適用地區的依據。台灣期間依作品類型和作者狀態而異。公開範圍超出已確認地區時，先補足證據。 [著作權法第 30–35 條](https://law.moj.gov.tw/LawClass/LawAll.aspx?PCode=J0070017) |
| 已授權 | 記錄授權方及授權資格、涵蓋的版本、條款或文件、有效期間及區域，確認允許本集所需的翻譯、改寫、影音改作、YouTube 傳輸與廣告營利。記下限制、署名及其他履行方式。個別條款不明時先釐清。 [著作權法第 37 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=J0070017&flno=37) |
| 需個案評估 | 權利依據仍不清楚時記為待確認，記下缺少的事實和證據。只有具體依據足以支持預定用途後才能轉為通過。 |

Creative Commons 授權要記錄版本、被授權的具體素材及授權方。CC BY 支援商業改作並須履行署名等條件。CC BY-SA 另須以相同或相容的條款分享改作，並確認發布方式能履約。帶 NC 的授權不足以支持營利使用。帶 ND 的授權不足以支持公開分享改作。另有許可時依該許可評估。 [Creative Commons 授權種類](https://creativecommons.org/cc-licenses/) · [相容授權](https://creativecommons.org/compatible-licenses/)

## 判定與交付

| 狀態 | 處理 |
| --- | --- |
| 通過 `approved` | 審查人已核對凍結稿及所需使用範圍，證據支持本次用途。原創作品的外部授權欄可填不適用並說明。 |
| 待授權 `pending_permission` | 已辨識需取得的權利，授權文件或所需範圍仍缺漏。保留為內部研究候選。 |
| 待確認 `pending_verification` | 來源、版本、權利歸屬、使用依據或相似性仍有疑義。保存待查項目，限內部研究。 |
| 拒絕 `rejected` | 已知權利條件與方案不合，或案源已決定停止使用。保留理由，改選題或另寫原創。 |

1. 選題時先記來源、暫定使用依據和預定用途。授權前可研究抽象機制或另寫獨立故事。
2. 製片前，審查人逐篇核對凍結稿 SHA-256 和下方權利紀錄。製片候選同時需要 Story Rights Gate 通過與 Story Quality Gate 通過。故事分數及相似性工具都無法代替證據。
3. 上傳前核對成片及雙語稿仍對應同一權利紀錄，並在發布前完成所需署名及條件。稿件版本、來源素材或使用範圍變更時更新紀錄，重審受影響的部分。公開仍依原有 Owner 授權及 Shorts Viewer Gate 流程。
4. YouTube 會獨立審查原創性、重複使用與大量模板化內容。保存每集腳本、分鏡、線索呈現與自製素材的紀錄，以說明具體創作貢獻。取得改作同意後仍須接受這些平台審查。 [YouTube 頻道營利政策](https://support.google.com/youtube/answer/1311392?hl=zh-Hant)

## 可複製的單集紀錄

將完成紀錄存於批次證據目錄。保留可追溯的來源與審查摘要。非公開合約或個資保存在安全位置，Git 中只放可供有權人查閱的文件索引。

| 欄位 | 填寫 |
| --- | --- |
| 故事及凍結稿 | ID、revision、稿件路徑、SHA-256 |
| 來源 | 原創作者或第三方作者與權利方、來源網址或書目、確切版本、查核日、Benchmark ID 如有 |
| 使用依據 | 原創／公共領域／已授權／需個案評估，以及證據位置 |
| 相似性 | 借鑑的機制、來源的具體情節元素、此稿有哪些獨立因果與表達、任何未解疑義 |
| 允許用途 | 分項記翻譯、改寫、影音改作、YouTube 上傳及公開、商業營利、區域及期間 |
| 履約 | 署名文字與位置、其他條件、確認結果 |
| 決策 | 預設待確認，另填狀態、審查人、審查日期、理由與待辦 |
