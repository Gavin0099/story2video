# H01 凍結剪輯探索盲測

**HUMAN_TEST_PENDING / EXPLORATORY ONLY**。2026-11-24 預先固定的方案；沒有招募、接觸受試者、上傳或執行真人測試。本次交付不構成這些動作的執行紀錄。兩版識別與不變雜湊見 [freeze.md](freeze.md)，已知混淆見 [temporal-qa.md](temporal-qa.md)。

問題：這支凍結 STILL 與這支凍結 MOTION，在首看吸引力、理解、自述揭露感受及自然度上有何描述性差異？**B 的手落下及抵門只有 partial motion**，且有道具／角色連續性問題；因此不能推論「動畫本身是否有效」、完整角色動畫效果或整個製作技術的優劣。

主持人知道 cut 並私下記錄；每次正式排程產生新的中性播放碼，實際 code key 只存在 gitignored 私密分派檔。Repo 是公開的，不能把實際播放碼與 cut、slot 或 seed 的對應放進公開文件。觀眾不看私密 key、分派表、製作紀錄、另一版或有版本資訊的檔名。播放視窗顯示中性碼，隱藏資料夾及檔名，不重新編碼影片。不告知有兩版、動畫比較、已知錯誤或「希望哪版贏」。這是觀眾單盲，不是主持人雙盲。

既有 [first-view-protocol.md](../first-view-protocol.md) 的 **Test A / Test B 是「3 秒停止」與「完整觀看」的觀察任務**，不是這裡的兩支 cut。本方案是獨立的 cut 比較，所有人都採一次不中斷的自然觀看，沒有強制第 3 秒停下。這裡不把 cut 稱作 Test A / Test B。

任何在本方案看過片段的人，即使提早退出，也已對 H01 曝光，**不能再算其他 H01 測試的 fresh first viewer**。看過 H01 任一稿、腳本、分鏡、相關解說、任一影片或既有首看任務者，事先標為不符合 fresh sample，不分派播放；不拿同一人補另一 cut。

## 樣本與先行分派

Between-subjects：**8–12 位**符合條件的觀眾，每人恰好一支 cut、一次。預設固定 **N=10（5 STILL + 5 MOTION）**。目前只有 10 個空名額，沒有參與者。不要看結果再決定擴到 12 或提前停止。

若招募開始前決定 N=8 或 12，分別為 4+4 或 6+6；N=9/11 時多出的一格也由 seed 隨機決定，兩組相差不超過一人。必須在第一次播放之前記錄改版理由、N、執行時間（Asia/Taipei）、Python 版本及分派檔承諾雜湊；seed 與分派保留在私密檔。保留舊檔與承諾，不按受試者特徵換組。實際不足就如實報 N，不虛構補齊。

### 先承諾、後揭露（commit-then-reveal）

1. 主持人在私密環境新建高熵 seed（建議以 Python `secrets.token_hex(32)` 產生），存入 gitignored `artifacts/genre-pilot-20261124/h01-viewer-gate-private/seed.txt` 或 repo 外的私密檔。不可使用日期、可猜數字或公開示範 seed。舊排程與舊播放碼已曝光，作廢，不用於真人測試。seed 不進 Git、公開日誌或命令轉錄；優先使用 `--seed-file`，`--seed` 僅供主持人私密環境傳入，程式沒有預設 seed。
2. 招募前固定 N，執行下方命令。程式 [assign_viewers.py](assign_viewers.py) 以 `random.Random(seed)`（seed 為字串）建立平衡 cut 池，奇數 N 先 `choice` 多出 cut，再 `shuffle`，最後產生兩個不同的六位中性碼。私密 JSON 包含 seed、N、Python 版本、完整 code key 與所有空 slot 分派，只有標準輸出的 SHA-256 可提前公開。這是空名額計畫，不是參與者或結果。
3. **第一次觀看前**，主持人在可查日期的公開紀錄發布完整檔案 SHA-256、發布日期時間（Asia/Taipei）、N 與方案版本，並填下方啟動欄及結果表。雜湊承諾只公開雜湊，不公開 JSON、seed 或對照。每次修改須在任何觀看前重新承諾，保留舊承諾與理由；開始觀看後不改排程。未完成附日期承諾不得開始。此文件未代替主持人發布，也尚未產生正式分派。
4. 主持人保管原始 JSON bytes；按到場順序使用 S01、S02……，不可挑名額。分派檔、code key、seed 與含 host cut 的原始答案均在私密位置保管，收集期間不 commit 或公開，不用公開 repo 的「主持人專用」標籤當作保密措施。
5. **全部回覆及排除／偏離紀錄鎖定後**，先記錄鎖定時間與答案快照雜湊，再公開原始分派 JSON（含 code key 與 seed）、揭露日期時間及先前承諾的連結。以 `Get-FileHash` 驗證原始 bytes 等於觀看前承諾；用相同 Python 版本、N、seed 重跑到另一個私密新檔並比對。若不一致，保留證據、標記偏離，不宣稱已遵守預先分派。揭露只含空 slot，不含個資；去識別答案另外處理。

## 一次觀看程序

1. 先確認從未接觸 H01；不透露劇情以做篩選。說明「請像平常看短片一樣觀看，隨時可以停止；沒有標準答案」。不展示劇本、問卷提示、揭露解說或 QA 問題。
2. 主持人在播放前填匿名碼、slot、中性碼、host cut、分派時間；核對 hash。播放凍結 MP4，英文音訊、**繁中 SRT 開啟**，兩組使用相同播放器／字幕設定、9:16 顯示、1×、同一手機／耳機及固定可舒適聽清的音量與相近環境。設備、字幕設定或條件偏離須逐人記錄，不為某組改善。SRT 是外掛；確認確實載入，不可誤以為 MP4 已燒字幕。
3. 不強制停 3 秒、不快轉、不重播、不講解。觀眾可隨時結束；主持人記開始、停止影片時間、是否到 3 秒、是否到完整輸入／SAVED（29.533333 秒）、是否看完 39 秒，以及技術中斷。提早退出是觀察資料，不因不喜歡而排除。
4. 結束／退出後，先以中性句「請用自己的話說剛才發生什麼」取得原話回述，不糾正答案；再填 [questionnaire.md](questionnaire.md) 的 6 題及 2 個開放題。Q1 是事後回想前三秒吸引力，不能冒充實際 3 秒留存率。揭露前的想法也是事後回憶，**不是預先鎖定的預測**。
5. 不詢問「燈是不是暗了」「門閂有沒有換」「動畫自然嗎」等提示。只記觀眾是否**自發**提到連續性、切姿勢、變形或任何其他問題，保留原話及其自述時間／位置。主持人可在答案收完後依 QA ID 編碼；沒有提到不代表沒受影響，記 `not mentioned`，不可記「無混淆」。最後才可補問中性的「還有其他想補充的嗎」。
6. 若未看至揭露，Q4 記 NA（未看到）、不是 1；其他無法回答／不願回答亦記缺值與原因。離場前不要播放另一版，不回頭改首看答案。主持人的事後解說不算答案證據。

## 預先固定的分析規則

- 每 cut、每題列 **有效 N、缺值 N、1/2/3/4/5 各計數及中位數**。偶數 N 的中位數取中間兩值平均；沒有有效值則 NA。列實際分派／觀看 N 及未曝光不符合人數（不收身分資料），各題分母不可偷換成總 N。
- 只有 6 題都有效才計總分 **/30**；實際可得範圍 **6–30**。缺題不補值、不以 0 代替、不外推為 /30；可另列完整問卷的總分分布及 N，不只報一個平均總分。
- 提早退出仍列入分派／觀看總數及可回答題目；技術故障、看錯 cut、已曝光或被提示，逐筆標記 protocol deviation。主表保留原始資料，另列符合程序的題目摘要，不靜默刪除不利回答。不把理解自評當成客觀理解，附原話回述與因果誤解。
- 不做顯著性檢定、p 值、信賴區間、因果效果估計或代表性人口推論。不以 /30 換算 /100，也不改既有 90 分 rule。這是探索，不作正式 PASS、影片驗收、擴產或公開核准。
- 總觀看 N<8、任一 cut 有效首看 N<4、分派失衡／曝光／技術偏離嚴重、關鍵題缺值多、兩組中位數相同、題目方向互相矛盾或差異主要隨自發提到的連續性問題而變時，結論可／應標 **INCONCLUSIVE**。若某題偏高，也只描述此樣本該題，不選「動畫贏家」。不得追加事後勝利門檻。
- 兩組共有的對講機／門閂／髮型問題，及 B 的 partial actions 都是 confound；逐人記是否自發提及、引用原話，與六題並列，不提示觀眾也不憑主持人猜測其心理。N 太小不能靠分組剔除「提到錯誤的人」來宣稱排除 confound。
- 即使 MOTION 的自然度或續看中位數較高，最多支持「此 B cut 在此小樣本的自述不同於此 A cut」。不能由此回答完整動畫是否值得、L2 是否普遍優於 L1、真實 Shorts 留存、訂閱、收入或 genre 市場需求。
