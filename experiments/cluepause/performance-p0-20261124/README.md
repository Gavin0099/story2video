## 資料定義與驗收

- 主表空欄表示該時窗缺資料，0 表示 Studio 顯示為零。比率欄是百分數，例如 72.1 代表 72.1%。平均觀看的中位數以有正數首日互動觀看、且該項可讀的作品計算。第一個明確線索可能早於題面，例如〈尋人啟事〉。〈移動的茶杯〉的首見異常欄留空，開場有旁白，抽幀未能確認明顯位移。
- D1-A／D1-B 是舊批次已保存的「前 24 小時」視圖。D1-C 加序號是進階模式的同窗報表。D1-D 是單片參與度上排，D1-E 是單片影片洞察的觀看數。欄位若有不同時間的讀值，採較晚讀取結果，列內保留來源代號、抓取時間和更新欄位。YouTube 的縮圖曝光與縮圖點閱率另列，衡量 Shorts 開場需要動態曝光及續看。 [YouTube Studio 進階模式](https://support.google.com/youtube/answer/16766491?hl=zh-Hant) · [Shorts 數據定義](https://support.google.com/youtube/answer/12220281?hl=zh-Hant)
- 參與度下方的續看百分比、〈刪除試鏡〉和〈生日視訊〉已顯示的逐秒曲線，卡片標明「自影片發布至今」。第二份表也保存舊批次 2026-10-26 至 11-22 的 Studio 匯出值。補查首日後，先列出各指標有效樣本數，再比較同窗逐片中位數，並標記動態曝光或流量來源不足的比較。 [YouTube 觀眾留存報表](https://support.google.com/youtube/answer/9314415?hl=zh-Hant)
- 成片時間以 MP4 抽幀及同版字幕或時間軸交叉核對。主表保存 SHA-256，26M B 對應 Studio 下載檔。版控只保存正規化資料與分析，取證畫面留本機。
