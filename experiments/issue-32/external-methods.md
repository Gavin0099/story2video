## 工程與市場驗收

- 研究基準為 story2video `44fccc8d6184d15561395c657d121e9aa3128a31`。固定版本連結與遞迴樹比對，其中超出樹列印上限的部分以 GitHub contents API 或固定 SHA 原始封存重驗。登錄文件工程查核以這些資料、連結與差異格式為主。
- 工程為只讀查核。用 `gh issue view 32 --repo Gavin0099/story2video --json body`、`gh api repos/OWNER/REPO`、`gh api repos/OWNER/REPO/commits/main`、`gh api 'repos/OWNER/REPO/git/trees/SHA?recursive=1'`、`gh api 'repos/OWNER/REPO/commits?sha=main&per_page=1&path=PATH'` 取得範圍、版本與活動。16 份固定 SHA 原始封存均可取回，讀取標示的 Markdown、設定和部分入口程式。所列程式查到輸入、依賴、網路和寫入面為止，尚未做第三方完整安全、轉授權、模型資產或依賴鏈審計。未安裝或執行上游程式、未使用生成／發布服務。採用的文字方法已接到批次 Skill 的編輯與交接步驟。
