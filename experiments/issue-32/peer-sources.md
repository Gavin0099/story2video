重驗方式為把各原片 ID 帶入 `curl.exe -Ls "https://www.youtube.com/watch?v=VIDEO_ID"`，從 HTML 中查 `ytInitialPlayerResponse` 的 `videoDetails.viewCount`、`videoDetails.lengthSeconds` 與 `microformat.playerMicroformatRenderer.publishDate`。頁面累積觀看將隨時間更新。
