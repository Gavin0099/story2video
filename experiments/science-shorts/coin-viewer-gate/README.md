# 硬幣篇首看測試

第一輪驗證一件事。受試者在手機上可以立即離開時，先看到「杯緣擋住硬幣 → 倒水 → 硬幣出現」，是否更常停到三秒，而且能說出剛才發生什麼？

| 項目 | A | B |
| --- | --- | --- |
| 前三秒 | [已公開版本](https://www.youtube.com/shorts/NsZLF8Qeryo) | 固定視角的原創示意動畫。畫面從杯緣遮住硬幣開始，倒水後顯露硬幣。 |
| 固定 | 同一個約 38 秒的 MP4、原有英語旁白和 AAC、同一份繁中字幕、相同播放器和原有音量。 | 只在 0–3 秒將動畫疊到原圖區域。到了 3 秒即顯示原片，全程共用 A 的影像和音軌。 |

[B 版 MP4 預覽](../../../artifacts/science-shorts/coin-viewer-gate/B-preview.mp4)另行編碼，適合先看片。正式記錄透過手機試看頁，字幕及 3 秒後畫面由共用的原檔提供。

## 主持流程

1. 以一般有聲組為主要比較，每版預先分派 12 個代碼。依主持表每組分派順序發一人一碼。看過這題、參與製作或試看過的人勿再納入。主持人使用中性的同一句話「像平常一樣看短片，想離開時可以往上滑」。觀看前說明記錄匿名停留時間、回覆自願。主題、假設、正解與其他版本都在觀眾提交前保密。
2. 用直式手機、同類型設備或均衡分配機型，保持普通有聲組相同音量和繁中字幕。從播放後實際影片時間算起。受試者可以上滑、點「往上滑」或等自然播完。看過一版即結束。切到背景或播放器錯誤記為無效，保留退出情形。播放時間自行下載後交給主持人。
3. 另外安排沒看過的獨立靜音組，先每版約 4 人探索。音訊和字幕皆關閉，保留原本的英文標題、品牌與圖內文字。紀錄首看有沒有說出「倒水」及「原本看不到硬幣，後來看到了」。特別記下有沒有人把示意理解成硬幣浮上來。靜音組的結果各自呈現。
4. 正常播放後用兩個自願填答的開放問題「剛才的畫面發生了什麼？」、「你覺得是什麼原因？」。主持人先去掉版本欄再判讀答案。正確原理需表達光從水進空氣時改變方向，因而能越過杯緣進眼睛。接受日常用語。只說「水讓硬幣出現」、「硬幣浮上來」或「硬幣被水放大」分別記為描述、誤解或其他，無答案保留空值。
5. 一人一筆。用代碼核對主持表，去除重複與外部干擾。先報列有效樣本、各版 3 秒留存人數及分母，再報完播人數、中位觀看時間、答對人數、答題人數與誤解摘錄。理解率同時列「答對／已作答」及「答對／全體有效樣本」。10–12 人一組是小樣本，只能決定是否值得再跑或改版。若方向不一致，新增一批觀眾或另做固定視角、同揭露時間的實驗。

## 本機開啟

從 repo 根目錄執行。試看頁使用本機的 Node.js，只有一個靜態伺服器，結果由參與者下載，不會傳回伺服器。

```powershell
node experiments/science-shorts/coin-viewer-gate/serve.mjs
```

上面的指令預設只聽本機。主持人可先打開 [A 版](http://127.0.0.1:8765/?preview=A) 或 [B 版](http://127.0.0.1:8765/?preview=B)。正式試看用 [不標版本的入口](http://127.0.0.1:8765/) 和 [主持人分派表](../../../artifacts/science-shorts/coin-viewer-gate/host-assignments.csv)。手機試看時，主持人可把同一指令的第一個參數改為電腦的區網 IP，並用同一區網打開該 IP 的 8765 port。先找一台 iPhone 和一台 Android 預演開始、字幕、滑走、下載和交付。這些預演紀錄在正式分母之外。把分派表與匿名 JSON 放在主持人手上。

需重建素材時，用具有 Pillow 的 Python 執行 [build_pilot.py](build_pilot.py)，並提供本機 FFmpeg 的絕對路徑。

```powershell
& artifacts/render-venv/Scripts/python.exe experiments/science-shorts/coin-viewer-gate/build_pilot.py --ffmpeg artifacts/render-tools/verified/ffmpeg-9.1-essentials_build/bin/ffmpeg.exe
```

等硬幣篇有足夠真人結果後，再決定是否將「先見到現象」用於紫高麗菜篇。這次 B 同時調整畫面和揭露時點，結果的比較單位是整套前三秒開場。
