## 每輪怎麼做

1. **選題。** 每輪先寫三篇。從題庫挑出不同題材，每題先填「觀眾看見什麼」「哪個條件改變」「最後能用一句話解釋什麼」。用這三項和舊題去重，同一機制只換道具時先擱置。
2. **查來源，再寫。** 每個核心主張找兩個獨立發布者的可核對資料。記錄適用條件，再寫英文口說稿與逐段繁中字幕。先讓觀眾看見現象，再用一個比較或視角變化講清機制，結尾回到原場景。圖解標示採英文，製作時再按實際配音對齊字幕。
3. **獨立盲評。** 延用兩位讀者各至少 85 分。先各自只看開場，回答這支片會解釋什麼，再讀完整稿和畫面提示，回答重述題與變化題。另做獨立事實與圖解審查。保留原稿、各次評分與修改原因，核心說法有誤就先修稿。[既有評分規約](../batch-20261121/gate-policy.json)
4. **凍結、試拍、排程。** 把通過的版本標為「文案凍結」。優先做能看出因果關鍵的前幾鏡，實際驗過畫面再做整支。成片完成審查與 QA 後才進待發布列，依當時額度和既有授權安排。
5. **用已發布影片的資料修下一輪。** 按各片實際公開時間比較首 24 小時的有效觀看、繼續觀看比例與平均觀看百分比。保留開場做法及使用的畫風版本。對比同類題目時，每輪優先改一個因素，例如先用實拍現象開場，或提早顯示核心比較。樣本少或資料還在處理時，先記觀察再繼續累積。[首日成效紀錄](../public-20-20261122/d1.csv)

每篇記錄集數與版本、英／繁中標題、開場、一句核心機制、對照變因、雙語逐段稿、視覺重點、來源、盲評題與狀態。建議狀態依序記「題目候選 → 已有來源 → 待獨立審查 → 文案凍結 → 待成片驗收 → 待發布 → 已公開」。文案有改動就留新版本，將審查結果連回當時讀到的版本。

起步可保留 **3–6 篇已凍結、尚未製作的新稿**。剩不到三篇時，再依上線結果補寫一輪。舊批次的成片另由發布紀錄追蹤，寫作進度可以先於錄音與製片。
