## 審查與計分

- 事實審查 agent 逐篇核對旁白、關鍵主張與來源。圖解審查由另一位 agent 逐篇核對因果順序、對照條件、運動方向與拍攝可行性。10 篇均通過兩道審查。
- 每篇由兩位獨立盲評 agent 分兩段評閱。先讀開場並寫下以為這支片會回答什麼，再讀完整雙語旁白與分鏡，用自己的話解釋原理並回答一道情境題。各盲評於獨立對話執行，評閱資料限於當輪素材與問題，彼此的答案和評分未提供給其他讀者。
- 單份滿分 100，包含開場 15、清晰度 25、因果複述 25、圖解 20、節奏 10、雙語自然度 5。每位盲評均達 85 且答對兩道理解檢查，事實與圖解審查均無阻擋問題，才收錄正式稿。
- 盲評 1 為讀者 A，盲評 2 為讀者 B。WNL-022 的 v2 理解題超出腳本提供的定性資訊，修正後由新讀者 C 和只看過開場的讀者 B 分別盲評 v3。表中 WNL-022 的 95 分來自讀者 C，有效門檻取 v3 的 95 和 93。
- [逐篇分項、審查摘要和稿件版本](reviews.json) 包含整份稿件雜湊。盲評另有旁白與分鏡雜湊，可核對實際提供讀者的段落。盲評原始回答保留於本機。

## 製片交接

圖解標籤使用英文，繁中提供在字幕台詞。每篇的「對照與製作條件」記錄目前需要保留的視覺控制。WNL-024 製作時要先試拍兩塊冰的差異，並讓桌拍與低溫路面模型的溫度條件能連起來。WNL-029 的音高切換要隨波峰抵達聽者的節奏變化。

目前驗收涵蓋稿件、來源與分鏡，以及 agent 對腳本的理解。實拍、配音、剪輯、成片觀看測試與市場數據屬製片與發布階段。

在 repo 根目錄執行以下指令，可核對稿件版本、審查人、分項分數、索引與來源格式。

```sh
python -X utf8 experiments/science-shorts/script-library/batch-001/verify.py
```
