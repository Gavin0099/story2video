# WNL-028｜這片葉子的黃色，原本就在裡面嗎？

**English title**  
Was This Yellow Already in the Leaf?

**題材** 植物科學 · **版本** v1 · **機制** `chlorophyll-carotenoid-unmasking`

## 影片說明

Follow the yellow in a changing leaf and see what happens when green chlorophyll fades.

沿著轉色葉片的黃色一路看，找出綠色葉綠素變少時，哪些顏色變得明顯。

## 對照與製作條件

限定秋天由綠轉黃的常見情形。鏡頭用同一片葉或一致的原創動畫；色素符號呈現綠色遮蔽減弱，不呈現顆粒實測比例。
