## 審查與計分

- 每篇的事實審查與圖解審查由兩位不同 agent 執行，確認核心主張各有不同發布者的來源，並核對分鏡的因果順序與對照條件。
- 兩位盲評各先讀開場並說明期待影片回答的問題，再讀完整旁白與分鏡，完成因果複述與情境推論。盲評在各自的對話進行，依階段提供素材，來源、答案與其他讀者的評語均未提供。
- 單份滿分 100，包含開場 15、清晰度 25、因果複述 25、圖解 20、節奏 10、雙語自然度 5。每位需各達 85 分並通過理解檢查，事實和圖解審查也須通過。
- WNL-038 的 v2 首輪讀者給 83／88，修正開場、上游蓄水和持續出流的對照。WNL-040 的 v2 首輪讀者給 89／90，但讀者 A 指出兩塊羊毛的處理條件未在旁白說清楚。v3 交代同樣泡水、只揉一塊、兩塊都晾乾後做比較。
- WNL-038、WNL-040 表中列的是全新讀者 C、D 對 v3 的兩份盲評。其餘列出讀者 A、B 的結果。
- [完整分項、事實與圖解評語](reviews.json) 含精確的稿件與分鏡雜湊。盲評原始答案及首輪修稿證據保留於本機。

## 製片交接

河狸篇用固定角度和水位標記，讓觀眾同時看見上游蓄水與下游還在流。羊毛篇的阻力箭頭需要清楚標明其含義，以免看成纖維位移。QR 碼篇兩種遮片位置要先試掃，恰當呈現該次觀察的結果。

本批驗收涵蓋稿件、來源與分鏡。實拍效果、配音長度、字幕同步與手機畫面在製片階段驗證。市場成效在發布後觀察。
