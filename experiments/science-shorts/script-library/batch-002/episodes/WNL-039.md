# WNL-039｜古屋木梁沒有日期，考古學家怎麼知道它的年代？

**English title**

How Can Tree Rings Date an Old Wooden Beam?

**題材** 考古定年 · **版本** v2 · **機制** `tree-ring-crossdating-archaeological-timber`

## 影片說明

Match a beam's pattern of narrow and wide rings against a dated reference. The last surviving ring tells you which date the wood can support.

把木梁上窄寬交錯的年輪和已知年份的序列對上。最外側保留下來的年輪，決定我們能把日期推到哪裡。

## 對照與製作條件

使用原創木材示意與虛構年份，房屋與木梁不套真實遺址名稱。模式採同區、有共同生長訊號且足夠長的參照，動畫只抽取可見區段。必要時由標本與多筆比對驗證。從年輪可定到的是木材生長年份，建造年代另須考古證據。
