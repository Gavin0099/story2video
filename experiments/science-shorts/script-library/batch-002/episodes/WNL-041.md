# WNL-041｜QR 碼被遮住一塊，為什麼有時還能掃出原本的內容？

**English title**

Why Can a Partly Covered QR Code Still Scan?

**題材** 資訊編碼 · **版本** v2 · **機制** `qr-reed-solomon-error-correction`

## 影片說明

Cover part of a homemade QR code and test the scan. Extra encoded information can help reconstruct the original message within limits.

蓋住自己印的 QR 碼一小部分，再掃一次。額外編入的資料能在一定範圍內幫忙重建原本的訊息。

## 對照與製作條件

用自製純文字 QR Code Model 2，不使用外部網址、個資或真實憑證。兩種遮片位置需先實掃驗證，保留角落定位圖案與外圍留白。動畫標為概念示意，不畫成真正碼字在實際 QR 版面的分組。不要用被遮住的圖形面積推論固定可復原比例。
