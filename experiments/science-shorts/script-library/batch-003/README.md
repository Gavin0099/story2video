## 審查與計分

- 事實和圖解由兩位不同 agent 審查。每個核心主張由不同發布者的來源交叉查核，逐鏡確認圖解機制與對照條件。
- 兩位盲評在各自對話先讀開場，說明期待解答的問題，再讀雙語旁白與分鏡，完成因果複述和新情境推論。提供的素材只有該輪所需的稿件及提問。
- 滿分 100，分為開場 15、清晰度 25、因果複述 25、圖解 20、節奏 10、雙語自然度 5。兩位讀者都要至少 85 分，兩道理解題都須答對，事實和圖解也須通過。
- 蜂蜜篇 WNL-043 首輪為 90／94。第一位讀者指出側彎到成圈缺少可追蹤的過程。v2 追蹤同一彎折到完整一圈，並看見供料停止到尾端落完。表中 95／92 由兩位新讀者獨立給分，其餘採計 A、B。
- [完整分項、事實與圖解評語](reviews.json) 含定稿與分鏡雜湊。盲評原始答案及修稿記錄保存在本機。

## 製片交接

蜂蜜篇先預試穩定繞圈，再用同一落點由側視接俯視。生日篇逐次亮出已用日期，機率條另外標示為模型計算。GPS 篇把實際路徑固定，四筆估計值才同步偏移，用數值和線型區分。

本批驗收涵蓋稿件、來源和製作前分鏡。實拍、配音與字幕對時、手機畫面預覽和市場成效待各階段驗證。

在 repo 根目錄執行下列指令可核對第三批稿件版本、評分及審查資料。
