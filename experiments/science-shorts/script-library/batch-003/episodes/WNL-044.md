# WNL-044｜火車左右輪一起轉，外側輪怎麼走得更遠？

**English title**

How Can Two Train Wheels Turn Together but Travel Different Distances?

**題材** 鐵道工程 · **版本** v2 · **機制** `rail-wheelset-rolling-radius-in-curves`

## 影片說明

The outer rail is longer around a curve. A tapered model wheelset can cover that extra distance with the same number of turns on both sides.

彎道外側鐵軌比較長。用有斜面的輪組模型看出兩輪轉一樣多圈時，外側如何走得更遠。

## 對照與製作條件

示意為硬軸、斜踏面、適合曲率與足夠橫移的理想純滾動。實車亦有輪緣、懸掛與接觸滑移等因素。使用桌上模型或原創動畫。
