## 審查與計分

- 事實和圖解由不同 agent 審查。每個核心主張由不同發布者的來源交叉查核，分鏡核對畫面內可追蹤的因果與對照條件。
- 兩位讀者在各自對話先單獨看開場，再看完整雙語旁白和分鏡，分別回答因果複述與情境推論。提供的素材只有該輪稿件與題目。
- 滿分 100，包含開場 15、清晰度 25、因果複述 25、圖解 20、節奏 10、雙語自然度 5。兩人都要拿到至少 85 分並答對兩道題，事實和圖解也須通過。
- WNL-060 首輪是 98／94。v3 指定手機上十字、圓點位置與起始距離。最終情境題改問張開另一眼會如何，兩位新讀者 I、J 都答對，獲 96／97。
- WNL-061 首輪是 95／92。v5 加入同深度、各自近似等速的同步量測與空行程對照，收尾明確區分慢壓與快壓。最終情境題改問顆粒較少時是否同樣容易卡住，讀者 I、J 都答對，獲 95／96。其餘八篇採計 A、B。
- [完整分項、事實與圖解評語](reviews.json) 含定稿與分鏡雜湊。盲評原始答案與修稿記錄保存在本機。

## 製片交接

盲點篇要先在手機播放器實測兩個標記的位置，圓點需避開播放器按鈕。巧克力篇控制同配方、模具與保存條件，並在調溫圖標出回溫留下種晶。玉米粉水篇在兩個等速區段取相同深度的力值，結尾沿用開場的同一組數值。動畫一路保持連續水相。

本批驗收涵蓋稿件、來源及製作前分鏡。實拍結果、配音與字幕對時、手機可讀性和市場成效待各階段驗證。

在 repo 根目錄執行下列指令可核對第四批稿件版本、評分及審查資料。

```sh
python -X utf8 experiments/science-shorts/script-library/batch-001/verify.py --batch batch-004
```
