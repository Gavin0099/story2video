# WNL-053｜各拔掉一顆燈泡，為什麼一邊全暗、另一邊還亮？

**English title**

Why Does Removing One Bulb Turn Both Off in Only One Circuit?

**題材** 直流電路 · **版本** v2 · **機制** `series-parallel-lamp-open-path`

## 影片說明

Two pairs of bulbs start on. Remove a bulb from each and trace which circuit still has a path back to its battery.

兩組小燈原本都亮著，各拔掉一顆後，只有一組還能亮著一顆。沿著電線看看哪裡仍有完整回路。

時間為口說與剪輯預估，實際字幕時間軸依錄音對齊。畫面採 9:16，圖解標示用可編輯的英文文字。

| 預估秒數 | English narration | 繁中字幕 | 分鏡與圖解 |
| --- | --- | --- | --- |
| 0–10 | Both boards have two lit bulbs. Remove one from each, and only one board goes completely dark. What’s different about the wires? | 兩塊板上各有兩顆燈亮著。各拔掉一顆，只有一塊板全部熄滅。電線接法差在哪裡？ | 滿版桌面以相同機位逐次示範兩塊低壓電路板。先讓四燈亮，再用手鬆開兩塊板同位置的教具燈泡，拍到不同結果。 |
| 10–20 | On this board, the wires make one loop. Current has to pass through both bulbs to get back to the battery. That’s a series circuit. | 第一塊板的電線只有一個回路。電流要經過兩顆燈，才能回到電池。這叫串聯。 | 原位描出 Series 單一路徑，兩燈在同一圈。用短動畫說明接到電池兩端，勿顯示電子減少。 |
| 20–27 | Remove either bulb and you leave a gap in that one loop. Current stops flowing through both bulbs. | 拔掉任一顆燈，唯一的回路就斷了。兩顆燈都沒有電流通過。 | 維持線圖與燈泡位置，空燈座旁標 Open circuit。顯示整條原有電流路徑同時變灰。 |
| 27–37 | The other board puts each bulb on its own branch. Remove one and the other branch still makes a complete loop through the battery. | 另一塊板上，每顆小燈各有一條支路。拔掉一顆，另一條支路仍能經過電池形成完整回路。 | 切換第二塊板，同角度疊 Parallel。灰掉斷路支路，沿未斷支路和共用主線描回另一個電池端。 |
| 37–45 | Follow the closed path and you can predict which bulb will stay on. | 找出還接得通的回路，你就能預測哪一顆燈會繼續亮。 | 原兩塊板同框，以實際發光結果收尾。保留 Series / Parallel 兩標籤。 |

## 對照與製作條件

用有絕緣燈座的低電壓教具、額定相符的兩組小燈與受控開關。可用額定教具的操作方式鬆開燈泡，以同一燈座位置比較兩板。只比是否亮起。
