# WNL-057｜同一種巧克力，為什麼一塊亮又脆？

**English title**

Why Does Tempered Chocolate Snap?

**題材** 巧克力材料科學 · **版本** v2 · **機制** `cocoa-butter-form-v-tempering`

## 影片說明

Two bars start with the same dark chocolate. A controlled melt and cool changes how the cocoa butter sets.

兩塊都來自同一種黑巧克力。控制融化和冷卻的過程，會改變可可脂凝固的方式。

## 對照與製作條件

用同一批黑巧克力、同款模具與厚度、最終溫度、養置時間、光與收音，只有一份按材料規格調溫。預試可見對照後再拍，結果可能依配方、冷卻及微結構而變。示意晶體非實測影像。
