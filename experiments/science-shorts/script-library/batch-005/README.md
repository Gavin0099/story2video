## 審查與計分

- 事實與圖解分由不同 agent 審查。事實審查交叉查核不同發布者的資料。圖解審查核對每段畫面能否呈現因果，以及演示是否控制相關條件。
- 兩位讀者各自先看開場。提交開場分數後，再各自看該篇定稿的雙語旁白和分鏡。每篇都要複述因果，並回答一個延伸情境。
- 滿分 100，含開場 15、清晰度 25、因果複述 25、圖解 20、節奏 10、雙語自然度 5。兩位各達 85 分，兩題均答對，且事實與圖解皆通過後才收錄。
- 輪胎篇改用兩種排水來源的判讀題，讀者 C、D 複測通過。荷葉篇首輪 82／82，v4 補上水珠後緣帶起同一顆粒的連續畫面，讀者 D、E 複測通過。其餘八篇採計讀者 A、B。
