## 審查與計分

- 事實與圖解交由不同 agent 審查。每篇的核心主張由至少兩個獨立發布者的資料支持。
- 讀者先各自看開場，鎖定開場分數後才各自看定稿的雙語旁白與分鏡。每篇都要說出因果，再用同一個原理解釋新情境。
- 各項滿分為開場 15、清楚度 25、因果複述 25、圖解 20、節奏 10 和雙語自然度 5。兩位各至少 85 分，且兩題答對才通過。
- 等面積拼磚篇首輪 81 分。v3 加入從中心分成三角形的面積推導，並將結論明確寫為每格分攤的邊界總長。美乃滋、烏賊和等面積拼磚三篇採定稿的 B、C 分數，其餘採 A、B。
- [完整分項、事實與圖解評語](reviews.json) 可核對稿件與分鏡雜湊。

## 製片交接

- 斜坡競賽須先從實拍驗證兩輪無打滑。冰河篇的地形、縮時與示蹤位移採用標明的原創模型，基底滑動與內部流動分開呈現。
- 自動鉛筆須選和示意機構一致的筆，保留筆尖與筆芯追蹤點。美乃滋要從攪拌拍進分滴，再比較有無乳化層的碰撞。
- 暖暖包的兩支探頭量的是各自的外表面。土星環內有環紋，繪出的局部環粒軌道需標示為示意。影片與資料來源中的實拍素材要保留授權及署名紀錄。烏賊篇要從畫面辨識出主體，避免近拍斑點像其他皮膚反應。
- 本批驗收至稿件、事實來源與分鏡。各演示的實拍結果、定稿配音、字幕對時、手機可讀性與市場成效待驗證。
