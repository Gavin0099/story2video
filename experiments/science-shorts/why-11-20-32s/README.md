## 驗收紀錄

- **成片。** 十支通過編碼後技術檢查及兩位審查員分組做的獨立科學、圖解抽查。每支目錄內有輸出 SHA-256、畫面抽樣、旁白排時與完整解碼紀錄。人工看片樣本時間及版本可用[上傳準備清單](../../../artifacts/science-shorts/why-11-20-32s/upload-handoff.json)中的證據路徑查閱。片型為 1080 × 1920、30 fps、H.264／AAC，兩個內嵌字幕軌與外掛 SRT。
- **剪輯選擇。** 沿用原本通過事實與雙盲評分的旁白與 AI 輔助插畫，重排動態圖解與字幕時間。部分較長集數刪去一段旁白，保留段落的口述文字沿用原稿。第 11 支的開場用已盛滿且已有小水珠的杯子，觀眾會看到水滴成長和滑落，倒飲料由旁白補述。第 17 支加了合成示範音，靜音時仍可比較振動。原稿分數沿用舊紀錄。
- **工程。** Git 基準 `2d63c2d2fa70d43e1a60b3fa7ec5a11664d341ea`。`uv sync --locked` 和 `uv run --locked pytest` 通過 61 項。`npm ci` 與 `npm run typecheck` 通過，本機 Node 24.13.0 和 README 指定的 Node 22 不同，安裝時出現版本警告。成片腳本使用 Python 3.12.10 和 FFmpeg 9.1，輸入需保留原批次本機素材。晾衣篇的左右位置依審查回饋修正後重渲染，兩批成片對應的 renderer 版本各自記錄在技術紀錄內。
- **真人觀察。** 可先用 12、16、17、18、20 做五題試看，分別覆蓋力矩、熱伸縮、聲音、週期運動和毛細現象。在手機上先記觀眾到第 3 秒能否指出畫面變化，再記錄看完能否用自己的話說出原因。真人首看、成片新盲評分數及 Studio 留存目前尚無資料。五題只是敘事流程能否跨題材的試看組。
