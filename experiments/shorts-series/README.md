## 發布後觀察

每集在第 7 天與第 28 天各記一筆累計資料，使用從正式發布起的固定範圍，另填實際讀值日。若報表延遲，保留原觀察窗並在資料齊後回填。只有 Studio 回傳實際零值才填 `0`。[YouTube Shorts 分析指標](https://support.google.com/youtube/answer/12220281)

## 檢討節點

| 集數 | 驗證 |
|---|---|
| 1–3 | 可重現的製作流程、角色與場景一致性、雙語字幕與成本紀錄。 |
| 4–8 | 在相同觀察窗比較開頭、節奏和類型，記下主要流失位置。 |
| 9–12 | 對照曝光、留存、訂閱、回訪和製作成本，記下跨片重現的模式。 |
| 13–20 | 視首輪證據選擇是否追加，每次先寫明要驗證的假設。 |

工程驗證由產出、QA 和成本紀錄判斷。市場驗證使用正式發布後的資料。曝光太少或僅有少數影片收到曝光時，把市場結論標為「證據不足」，並記下缺少的樣本。
