## 給評分 agent 的資料

1. 用空白對話，每篇先只給第一段，收下首猜、依據和續讀意願。再給第二段和題目，收下鎖定猜測、信心與仍成立的替代解。也可一次給整張題卡，並明確記為一次讀完的測法。
2. 鎖定後才給對應的 [謎底](reveals.md)。按 [Story Quality Lab 量表](../story-quality-lab/README.md#怎麼判) 逐項給 1–5 分，指出支撐解答的已公開線索、可能的跳步，以及最影響續看的問題。
3. 收到 agent 的評分才對照 [作者自評](author-review.md)。若 agent 已看過含答案的 PR diff，該次可以記編輯評分，首次猜測則用另一個乾淨對話重測。

[英文故事稿](english-drafts.md) 含謎底，可在完成繁中盲讀後核對。第 01、02 集這次評的是文字修訂稿，已有試片各自保留原版本。英文口播時長、可切換字幕、成片品質和市場數據都在對應製作階段驗收。
