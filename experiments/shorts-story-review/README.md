## 開拍門檻

同一版須有 **三名全新的隔離分段讀者各達 90／100（含）**、題面支撐預先鎖定的核心答案，且無關鍵內容缺陷，才列為製作候選。修稿目標為 90–95 分。作者自評供修稿使用。修改題卡、謎底或英文稿後須重新封存版本。製作由使用者核准。

[評分與修訂紀錄](revision-review.md)保留各版結果。10〈刮痕〉在[第五稿](blind-tests/10-v5.md)三位診斷讀者均給 89 分，依約放回備選池。03、07 的新草稿、原始盲讀資料與判定見[首次 AutoLoop](autoloop/README.md)。08、12 保留為類型對照。

[AutoLoop 續跑紀錄](autoloop/continuation.md)收錄後續批次的凍結稿件與原始盲評。首篇製作候選為 [04 v7〈停在姓氏前〉](autoloop/qualified/04-v7.md)，三份正式盲評分數為 91、91、93。

## 給評分 agent 的資料

1. 用先前沒讀過故事的 agent。先只貼第一段，收下首猜、信心（0–100%）、依據及續讀意願（1–5）。再貼第二段和題目，鎖定終猜、信心、替代解，以及哪條線索改變理解。若猜測已鎖定，另外問揭曉前還想知道什麼。
2. 鎖定後才給對應的 [謎底](reveals.md)。記錄新增加的理解、猜中後是否仍感到意外，以及核心答案需要的資訊是否已在題卡出現。按 [Story Quality Lab 量表](../story-quality-lab/README.md#怎麼判) 逐項給 1–5 分，保留各項理由和加權總分。
3. 收到評分才對照作者記錄。若 agent 已讀過該故事、看過含謎底的 PR diff 或一次讀完整張卡，按實際接觸方式記錄。需要首次分段猜測時，用未接觸過內容的讀者另測。

[英文故事稿](english-drafts.md) 含謎底，可在完成繁中盲讀後核對。第 01、02 集這次評的是文字修訂稿，已有試片各自保留原版本。英文口播時長、可切換字幕、成片品質和市場數據都在對應製作階段驗收。
