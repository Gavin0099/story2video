# Story Quality Lab｜雙故事試跑

這輪各保留一個原稿對照，另做一個線索先行版和一個人物選擇先行版。六張題卡使用中性代碼。原稿是《窗裡的求救燈》的題面與提示，以及《他把海報貼了回去》上一支試片的繁中字幕。題卡目前只評繁中，英文改編另行驗收。

## 怎麼測

1. 每位第一次接觸故事的讀者，各拿一張窗與一張海報題卡。依序分派 67C → 94N、26M → 41K、73H → 58R 給前三位，下一組用相同配對逆序，之後循環。每張卡開始前先問讀者是否接觸過這則故事。讀過任何版本的人可提供編輯意見，該故事不計入首次盲測。
2. **每一輪只貼該段文字，以及當輪提問。** 主持人保留題卡原檔、GitHub 連結、另一段、答案和評分規則。以 58R 為例，第一次只複製從「水退以後」到「妻子伸手抽了回去」，收下首猜後，才貼從「告別式結束後」到「他為什麼還要把號碼換掉？」。揭曉詞等最終猜測鎖定才貼。
3. 兩段各記一次最可能的猜測、依據、替代解、信心（0–100%）與續讀意願（1 會停下、3 都可以、5 一定讀完，2 和 4 居中）。第一段尚未出現題目時，問「到這裡，你覺得發生了什麼？」。在第二段及每個問答回覆後，再問哪句資訊改變了理解。可以回答「沒有」。讀者若停下，記錄停讀輪次，該次試讀結束。
4. **海龜湯玩法**在第二段後開放最多三個是非問題。主持人依[編輯審查](editorial.md)回答「是」「否」「不限定」。每次只回應當前問題，收下新的猜測後才開放下一問。**短片敘事**依固定順序讀過兩段，直接鎖定。兩種玩法用不同的新讀者，資料分開比較。
5. 僅在讀者確認最終猜測後傳送同代碼的揭曉。請讀者指出哪個原先的理解改變、根據哪條揭曉前線索、有哪些替代解仍然成立、是否有改變答案但先前沒提示的設定，並記錄情緒（1 無感，5 強烈）。短片的實際口播與畫面另驗。
6. 完整稿偏好另做成對比較。讓同一組比較者讀同題完整的兩版，對調順序，允許平手。這組只問哪一版願意推薦、哪個動作更可信，以及原因。

AI 盲讀使用乾淨的工作階段，由主持人逐輪貼出同一套提問，保留實際送出的內容及原始回覆。發錯段落或讀者表示已看到後續內容時，記 FAIL 並回收該次樣本。投遞紀錄或讀者回報不明時，標記 UNKNOWN。

## 怎麼記

[讀者記錄表](reader-record.csv)已填入這次兩場 AI 複測作為範例。可另存一份副本保留欄名，清除範例列後填寫。每一列是一輪，用 session_id 匯集同場的資料，以 turn_no 保留順序，用 transcript_ref 對回完整原文。stage 依次填 part_1、part_2、q1 至 q3（有問才填）、lock、reveal、assessment。未執行的輪不新增列。最後一個是非回答若與鎖猜一起送出，就在 lock 填 question 和 answer，不重複新增問答列。空白代表該欄不適用或未收集。

| 檢查 | 欄位與判法 |
| --- | --- |
| **Leakage Check** | 比對實際送出及首次接觸回報。每輪在 exposure 記已接觸資訊，判定在 leakage_check。PASS 代表投遞符合順序且讀者回報無額外接觸，FAIL 代表確認提前接觸，UNKNOWN 代表缺乏紀錄。 |
| **Belief Shift** | belief_shift 依序寫原猜、改成什麼、是哪條線索或哪個是非回答。只提高信心時，記「猜測不變」，避免把每次問答都算作一次理解轉變。 |
| **Reveal Fairness** | 讀者在 reveal 逐一指出已公開的線索、仍成立的替代解及沒有提示的設定。以 SUPPORTED、PARTIAL、UNSUPPORTED 記錄。用 fairness_evidence 區分「所問的核心」與「用來收尾的補充細節」，並分辨哪些線索來自題卡、哪些來自是非問答。 |

每個是非問答都記 question、answer、guess、alternative、evidence。lock 依題卡自己的主持口徑填 core_match（FULL、PARTIAL、MISS 或 NOT_ASSESSED）。猜測列的 confidence_pct 和 continue_1to5 用前述量尺，若有計時才填 elapsed_seconds。assessment 兩道關卡各填 PASS、FAIL 或 PENDING，並附個別理由。AI 複測可以記錄發放和讀者反應，真人與實際短片還要分別驗收。

## 怎麼判

| 項目 | 可記錄的證據 |
| --- | --- |
| 海龜湯品質 | 猜測在第幾段或第幾個問題縮小、公開線索支持的推理、仍成立的替代解 |
| 短片敘事品質 | 第一段和第二段續看意願、停讀點、揭曉前後對同一個動作的描述、情緒反應、口播與畫面可行性 |
| 進入改編的硬性條件 | 原稿能自洽、人物行為有動機、核心因果已有線索、關鍵動作可以被拍到。兩道關卡各填 PASS、FAIL 或 PENDING，以獨立讀者紀錄及人工審片決定 |

編輯量表每項 1–5 分。懸念 20%、反轉與重新理解 25%、動機與情感 20%、因果 15%、公平性 10%、可視覺化 10%。1 代表明顯失敗、3 代表可理解但需修、5 代表具體證據支持。兩道硬關卡各自判定，即使總分高，缺乏動機或因果也仍需修稿。第一段就高信心猜中時，要再看讀者是否仍願意讀完。

## 怎麼用結果改稿

各版本記錄「修訂前的問題 → 改了哪一句或動作 → 期望看到的讀者反應 → 下輪是否重現」。先以兩題確認流程可行。同一題每個版本都只有少數人讀時，差異可能來自稿件、個別讀者或順序。第二輪可照相同方法擴到四類各五篇、每題兩個寫法。再加入刻意缺線索和答案不公平的對照，檢查兩關能否指出問題。

等有實際影片資料，再把版本對上續看／滑走、留存、完播與留言猜測，並記標題、縮圖和流量來源。小樣本先保留原始意見，權重等有更多真人資料後再校準。

人物改稿採用「角色、欲望、衝突、揭曉」四欄，參考 Truby 對人物因新資訊改變行動的分析。反轉檢查用獨立欄位記意外性與因果可信度。同題偏好比較以兩種順序呈現。 [The Anatomy of Story](https://us.macmillan.com/books/9780865479937/theanatomyofstory/) · [TwistBench](https://github.com/samjschapiro/twistbench) · [LLM Creative Story-Writing Benchmark](https://github.com/lechmazur/writing)
