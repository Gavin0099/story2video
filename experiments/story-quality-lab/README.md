# Story Quality Lab｜雙故事試跑

這輪各保留一個原稿對照，另做一個線索先行版和一個人物選擇先行版。六張題卡使用中性代碼。原稿是《窗裡的求救燈》的題面與提示，以及《他把海報貼了回去》上一支試片的繁中字幕。題卡目前只評繁中，英文改編另行驗收。

**主持人入口** · [題卡](readers/) · [揭曉詞](reveals.md) · [版本表與編輯審查](editorial.md) · [隔離 AI 讀者試跑](ai-readers.md) · [讀者記錄表](reader-record.csv)

## 怎麼測

1. 每位第一次接觸故事的讀者，各拿一張窗與一張海報題卡。依序發 67C → 94N、26M → 41K、73H → 58R 給前三位，下一組用相同配對逆序，之後循環。讀過其中某故事版本的人可提供編輯意見，該故事不計入首次盲測資料。任何階段均可停讀，照實記在表內。
2. 先給第一段，計時，記下第一猜、依據、繼續意願與信心。第一段若還未出現問題，主持人統一問「到這裡，你覺得發生了什麼？」有問題就沿用題卡。收下紀錄，再給第二段，記錄猜測是否改變、是哪句話帶來變化。主持人先保留版本說明和評分規則。
3. **海龜湯玩法**額外開一組新讀者。在第二段後固定給最多三個是非問題，依[編輯審查](editorial.md)的真相回答。猜中核心、替代解與補充細節分開登記。**短片敘事**採固定順序一次讀過並在第二段後鎖猜，讀者全程無法詢問。兩組結果分表比較。
4. 鎖定後才讀出同代碼的揭曉。請讀者指出前面哪個行為變了意思、哪些行為仍不合理、結尾有沒有情緒。另請編輯用一次朗讀計時，標出必須靠旁白才能解釋的拍點。文字體驗可用於選稿，發布後的實際留存要另記。
5. 完整稿偏好另做成對比較。同一組比較者可看同題完整的兩版，對調呈現順序，允許平手。這組只問哪一版願意推薦、哪個動作更可信，以及原因。任何人一旦看過答案，就結束該故事的首次盲測。

給 AI 的題面、提問和揭曉分開傳。先確認它只收到當前段落，逐次保存原回覆。任何同時看到題面和湯底的評估都歸入編輯審查。

## 怎麼判

| 項目 | 可記錄的證據 |
| --- | --- |
| 海龜湯品質 | 猜測在第幾段或第幾個問題縮小、公開線索支持的推理、仍成立的替代解 |
| 短片敘事品質 | 第一段和第二段續看意願、停讀點、揭曉前後對同一個動作的描述、情緒反應、口播與畫面可行性 |
| 進入改編的硬性條件 | 原稿能自洽、人物行為有動機、核心因果已有線索、關鍵動作可以被拍到。兩道關卡各填 PASS、FAIL 或 PENDING，以獨立讀者紀錄及人工審片決定 |

編輯量表每項 1–5 分。懸念 20%、反轉與重新理解 25%、動機與情感 20%、因果 15%、公平性 10%、可視覺化 10%。1 代表明顯失敗、3 代表可理解但需修、5 代表具體證據支持。兩道硬關卡各自判定，即使總分高，缺乏動機或因果也仍需修稿。第一段就高信心猜中時，要再看讀者是否仍願意讀完。

## 怎麼用結果改稿

各版本記錄「修訂前的問題 → 改了哪一句或動作 → 期望看到的讀者反應 → 下輪是否重現」。先以兩題確認流程可行。同一題每個版本都只有少數人讀時，差異可能來自稿件、個別讀者或順序。第二輪可照相同方法擴到四類各五篇、每題兩個寫法，先收閱讀資料，再決定哪些值得拍。

等有實際影片資料，再把版本對上續看／滑走、留存、完播與留言猜測，並記標題、縮圖和流量來源。小樣本先保留原始意見，權重等有更多真人資料後再校準。

人物改稿採用「角色、欲望、衝突、揭曉」四欄，參考 Truby 對人物因新資訊改變行動的分析。反轉檢查用獨立欄位記意外性與因果可信度。同題偏好比較以兩種順序呈現。 [The Anatomy of Story](https://us.macmillan.com/books/9780865479937/theanatomyofstory/) · [TwistBench](https://github.com/samjschapiro/twistbench) · [LLM Creative Story-Writing Benchmark](https://github.com/lechmazur/writing)
