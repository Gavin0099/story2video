# Shorts Viewer Gate

把吸睛與持續觀看當成同一件編輯工作。開場提出值得追下去的問題，中段給觀眾新的線索或因果進展，結尾兌現原本的期待。開場、是否繼續看，以及最後是否看懂，各用對應的證據驗證。

在 story2video 使用時，讀 [專案工作流與題型示例](references/story2video.md)。依使用者要求進到對應階段。只有腳本時，先用下面的方法規劃分鏡或提出假設。有片時，先看實際輸出的版本再診斷。

## 用成片時間碼檢查吸引力

| 看片段落 | 要確認的事 |
| --- | --- |
| 開場 | 手機直式正常播放一次。記錄第一次能辨認的異常動作、反差或結果，以及觀眾最早能提出問題的時間。以 0–3 秒作為 Shorts 的第一個抽查窗。視覺、旁白和字幕要指向同一件事。 |
| 持續觀看 | 標出每個線索、對比、關鍵動作和因果轉折的時間。寫出觀眾每次可以更新什麼猜測。若相鄰段落交代同一資訊，先改最早拖住進展的那一段。必要的觀察、推理與反應時間可以保留。 |
| 兌現 | 核對答案是否回到開場的同一個問題。在畫面或聲音上找出足以支持解答的證據，確認觀眾在接收答案時還能認出原本的情境。 |

按問題挑動手範圍。開場缺乏事件就試先看得到的動作或結果。中段停滯就試提早呈現下一條線索或下一個因果變化。結尾模糊就試把證據和結果放在同一個易辨認的動作上。每次有意義的畫面改變、音效、停頓與剪接，都要能說出它給觀眾什麼。需要獨立檢查畫面時，另做靜音首看，並記錄是否同時關閉字幕。

### 開場改剪與片長

- 安排第一幀已有可以辨認的動作或對比。若問題靠微小變化成立，先讓同一物件足夠大，固定視角和參照物，讓觀眾能自己讀出前後差別。標題與補充說明可以等觀眾看見事件再出現。字幕先提示觀察位置，揭曉文字跟著實際畫面出現。
- 開場展示現象或事件後，用下一個問題接住。科普可問「物件位置沒變，哪裡變了？」。海龜湯可讓觀眾看到反常動作，再追問動機。向前推進時只在有新線索、觀察角度或因果步驟的位置剪接。
- 片長由觀眾需要看清的證據決定。延長已驗看的版本時，保留開場畫面、聲音與揭露時間，把秒數留給控制變因、看清線索或比較結果。先看片指定的改動，再決定是否做控制條件相同的真人測試。

## 讓首看測試回答一個問題

- **依假設選主要指標。** 測開場用播放達 3 秒的人數／有效首看人數。測中段可用到達預先指定線索或解釋節點的人數，並記中位觀看秒數。測結尾可用到達揭曉、完播或能自行說出答案。分子、分母、排除原因與快進、重播等例外先定義。自願滑走屬有效結果。
- **用同一題的兩個版本比較。** 凍結 A 與 B，預先固定比較區間及其餘條件，例如語言、音量、字幕、總長和區間外的鏡頭。只分派一個版本給每位從未接觸過這一題的觀眾，盡量隨機且均衡。允許觀眾隨時離開。不同題目的觀察適合提出假設。
- **先記行為，再記理解。** 播放前使用中性說明及匿名代碼，觀眾離開或播完才自願回答「剛才有什麼變化？」和「你覺得為什麼？」。按題型另問關鍵畫面、線索或理解的轉變。主持人先定好答對口徑，留原話及未答狀態。理解同時報答對／已作答和答對／有效人數。靜音首看另用未曝光的觀眾。
- **交付可以核對的證據。** 記版本 ID、檔案或播放器素材雜湊、字幕與播放設定、時間碼、每組原始人數、觀看時長和代表性原話。把編輯看片、技術 QA、真人首看與公開後的市場數據各自標明。缺真人資料時標「待真人驗證」。小樣本報觀察方向和可能誤解。畫面與揭露時點同時改動時，結論適用於那一整段開場。

## 用市場數據回看影片

比較同頻道、相近片齡與流量來源。先查 Shorts 動態是否有人選擇觀看，再以平均觀看時長、觀看百分比和可取得的留存曲線定位段落。把掉點對到同一版本的成片時間碼，檢查首圖、第一個線索、圖解轉場和揭曉。曝光少或留存資料缺漏時照實記錄。本機 3 秒留存和 Studio 指標各按自己的定義報告。公開操作依當次授權。

交付依序給出最值得先處理的時間碼、目前證據、建議只改的一段，以及改完如何驗證。腳本分數與真人、Studio 證據使用各自原有的門檻。
